# 📊 Power BI Dashboard

This folder contains the Power BI dashboard developed for the **Enterprise SaaS Product Analytics** project.

## Dashboard Overview

The interactive dashboard provides a comprehensive view of product performance, user engagement, customer retention, subscription revenue, and business growth through four dedicated report pages.

### Dashboard Pages

1. **Executive Overview**
   - User Growth
   - Revenue Trends
   - Acquisition Channels
   - Geographic Distribution
   - Business KPIs

2. **Product Engagement**
   - DAU, WAU & MAU
   - Stickiness
   - Feature Usage
   - Event Distribution
   - Device Usage

3. **Revenue & Retention**
   - Monthly Recurring Revenue (MRR)
   - Annual Recurring Revenue (ARR)
   - ARPU
   - Subscription Status
   - Payment Analysis

4. **Growth & Experimentation**
   - Conversion Funnel
   - Cohort Retention Analysis
   - Upgrade Rate
   - A/B Testing
   - Feature Adoption

## Dashboard File

- `SaaS_Product_Analytics.pbix`

> Open the `.pbix` file using **Microsoft Power BI Desktop** to explore the interactive dashboard.
